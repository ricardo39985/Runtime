# Runtime

Intent-native software platform. C++23/Drogon core, Svelte 5 UI, TypeScript integration bridge, PostgreSQL durable state.

Implementation has started. This repository is not yet a production-ready application. The first milestone is a locally runnable, explicitly labeled development workflow with deterministic validation, durable state, exact-payload approval, and test-provider execution. Live identity, external integrations, and model-provider access remain separate acceptance gates.

No paid infrastructure is provisioned by repository initialization.
